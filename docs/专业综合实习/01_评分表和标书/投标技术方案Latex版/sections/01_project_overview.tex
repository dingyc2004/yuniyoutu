\section{项目概述}

\subsection{项目背景}

中国休闲渔业正处于持续增长阶段。根据全国水产技术推广总站、中国水产学会发布的《中国休闲渔业发展监测报告（2024）》，2023 年全国休闲渔业总产值达 931.47 亿元，同比增长 10.99\%，其中休闲垂钓及采集业产值 274.85 亿元；2024 年休闲渔业产值进一步增至 988.60 亿元，已恢复并超过疫情前高位。行业经营主体 14.04 万个、从业人员 82.38 万人、年接待 2.72 亿人次，表明垂钓已成为规模可观的休闲消费场景。

与此同时，垂钓用户群体正在发生结构性变化：年轻用户（尤其是路亚人群）增长迅速；短视频和社区平台上垂钓类内容年播放量突破千亿次；抖音电商 2025 年垂钓类商品累计售出 4.04 亿单。然而，当前用户在决定“去哪钓、能不能钓、有没有鱼”时，仍需要在地图、天气、潮汐、政策公告、钓友群、短视频和电商平台之间反复切换，决策成本高、信息可靠性不稳定。

\subsection{产品定位}

「鱼你有图」是面向钓鱼爱好者的垂钓 GIS 社交平台。产品并非通用地图或纯社区，而是把“地图找点、规则判断、鱼情推荐、鱼获发布、社区分享、教程学习”串成一条完整出钓链路，核心目标是帮助用户回答五个高频问题：

\begin{enumerate}
  \item 去哪钓？ — 基于 GIS 的垂钓 POI 发现与筛选
  \item 能不能钓？ — 禁渔区/禁渔期/限钓规则查询与风险提示
  \item 有没有鱼？ — 历史鱼获密度、近期鱼情与智能推荐
  \item 钓到了怎么分享和复盘？ — 结构化鱼获记录、战绩卡片生成与社区发布
  \item 新手怎么快速上手？ — 场景化教程学习路径与练习钓点推荐
\end{enumerate}

产品差异化在于：在成熟地图底图之上叠加“垂钓语义增强 POI”，将天气、水文、禁钓规则、历史鱼获和钓友评价整合到统一决策界面中。

\subsection{项目目标}

本项目为课程实习阶段的技术投标方案，当前目标是交付一个可演示的 MVP（最小可行产品）版本，验证核心业务闭环。

\textbf{本期课程实习交付范围：}

\begin{itemize}
  \item 完成“地图找点 → 钓点详情 → 推荐解释 → 发布鱼获/空军 → 社区展示”的主流程闭环
  \item 前端使用 Vue 3 + Vite + Element Plus + 高德 JS API 构建移动端界面
  \item 后端使用 FastAPI + Pydantic 2 提供统一 API，基于 JSON 文件实现数据持久化
  \item 推荐采用规则模型排序，AI（DeepSeek）负责生成自然语言解释
  \item 通过 JSON 文件原子读写保证新增记录和帖子在服务重启后不丢失
  \item 提供活动报名、群聊消息、装备订单、教程进度、个人报告等演示能力，用于展示后续服务扩展路径
\end{itemize}

\textbf{范围边界：}本期课程实习交付范围聚焦于地图找点、钓点 POI 展示、规则推荐与 AI 解释、鱼获/空军发布、社区鱼获流和基础教程展示；活动、订单、群聊和报告作为可演示扩展模块纳入展示。完整会员权益、真实支付与结算、正式赛事运营、商户后台、遥感自动识别钓点、权威规则数据合作和正式数据底座属于后续工程化扩展，不作为本期验收承诺。
