\subsection{产品定位}

「鱼你有图」是面向钓鱼爱好者的垂钓 GIS 社交平台，核心目标是帮助用户回答五个问题：
\begin{enumerate}
  \item 去哪钓？
  \item 能不能钓？
  \item 有没有鱼？
  \item 怎么钓？
  \item 和谁一起钓？
\end{enumerate}
