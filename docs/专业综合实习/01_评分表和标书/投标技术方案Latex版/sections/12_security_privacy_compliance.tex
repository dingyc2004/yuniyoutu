\section{安全、隐私与合规}

本章说明平台在数据安全、位置隐私、用户鉴权、内容治理和垂钓合规方面的设计。由于“鱼你有图”涉及用户位置、出钓记录、图片内容、社区互动、第三方 API Key 和个性化推荐画像，安全设计必须贯穿前端、后端、数据库、第三方调用和运维部署全过程。

\subsection{数据安全}

平台采用“密钥集中管理、传输加密、最小权限、可备份恢复”的数据安全策略。

\begin{itemize}
  \item \textbf{密钥管理：}高德 Web Service Key、DeepSeek Key、数据库密码、对象存储密钥均通过环境变量或密钥管理服务配置，不写入代码仓库、不出现在前端构建产物中。
  \item \textbf{传输安全：}平台统一使用 HTTPS；Nginx 负责证书配置和安全头设置，后端只接受可信网关转发的请求。
  \item \textbf{存储安全：}业务数据进入 PostgreSQL，数据库账号按环境和权限拆分；对象存储文件按公开、私密、审核中等状态控制访问。
  \item \textbf{备份恢复：}数据库每日增量备份、每周全量备份；对象存储开启版本管理或回收机制；上线前完成恢复演练。
  \item \textbf{日志脱敏：}日志记录接口路径、耗时、状态码和错误摘要，不记录完整密钥、明文密码、完整精确坐标和大模型原始隐私输入。
\end{itemize}

后端通过统一配置模块读取高德、DeepSeek、数据库和对象存储配置；前端 API 调用集中在服务层，便于统一追加鉴权头、错误处理、重试策略和权限提示。

\subsection{位置隐私保护}

垂钓位置具有明显隐私属性。精确钓点如果被无控制公开，可能造成个人隐私泄露、点位拥挤、环境破坏和合规风险。因此平台对位置展示采用分级控制。

\begin{table}[H]
  \centering
  \caption{位置隐私分级设计}
  \label{tab:location-privacy}
  \begin{tabularx}{\textwidth}{p{2.5cm}|p{4cm}|X}
    \toprule
    \textbf{级别} & \textbf{展示方式} & \textbf{适用场景} \\
    \midrule
    精确位置 & 展示具体 POI 或坐标附近位置 & 用户主动公开的商业钓场、公开水域或教程练习点 \\
    \hline
    水域模糊 & 展示水域、片区或 1-3 km 偏移后的范围 & 普通鱼获分享，既提供参考又避免暴露钓位 \\
    \hline
    仅城市 & 仅展示城市或区县 & 用户希望分享鱼获但不暴露具体位置 \\
    \hline
    完全隐藏 & 不展示位置字段 & 私密记录、敏感水域、用户未授权发布位置 \\
    \bottomrule
  \end{tabularx}
\end{table}

前端发布页面提供内容可见性和位置可见性选择；后端返回帖子和记录时再次执行脱敏，不能只依赖前端隐藏。数据库中同时保存原始坐标和展示坐标，原始坐标仅用于本人记录、统计和推荐计算，展示坐标按权限生成。

\subsection{用户鉴权与权限控制}

平台采用统一鉴权机制，可通过手机号、微信授权或账号密码登录，由服务端签发访问令牌。后端所有写接口必须校验请求发起用户身份，避免越权操作。

权限控制要求如下：

\begin{itemize}
  \item 用户只能修改和删除自己的出钓记录、帖子、评论、学习进度和订单。
  \item 管理员接口与普通用户接口隔离，管理员操作记录审计日志。
  \item 私密记录默认仅本人可见，生成社区帖子时需用户主动确认可见性。
  \item 活动报名、取消报名、签到等状态变更接口需校验用户身份和活动状态。
  \item AI 接口不接受任意用户传入内部系统提示词，不返回后端配置和调试信息。
\end{itemize}

接口采用 401/403 明确区分“未登录”和“无权限”，并在前端进行登录态失效提示。

\subsection{个性化数据授权}

个性化推荐依赖用户偏好和垂钓行为数据。平台必须在用户授权范围内使用相关数据，并允许用户关闭个性化服务或清除画像摘要。

授权控制包括：

\begin{itemize}
  \item 用户可设置是否允许使用出钓记录、收藏、浏览和教程学习记录优化推荐。
  \item Agent 只读取授权画像摘要，不直接暴露完整私密记录和精确坐标。
  \item 个性化推荐输出需说明主要依据，例如目标鱼种、偏好钓法、可接受距离或历史效率指标。
  \item 用户撤回授权后，系统停止使用其行为数据生成个性化推荐，并按策略清理或冻结画像摘要。
\end{itemize}

\subsection{接口与业务风控}

平台应对高频调用、恶意发布和异常写入设置基础风控：

\begin{itemize}
  \item 对登录、发布、评论、点赞、AI 解释、地图搜索等接口设置频率限制。
  \item 对帖子、评论和私信内容进行敏感词、广告、违法内容和人身攻击检测。
  \item 对图片上传限制格式、大小和数量，并接入图片审核能力。
  \item 对第三方 API 调用设置超时、重试上限和熔断，避免外部服务异常拖垮后端。
  \item 对数据写入接口进行 Pydantic 参数校验和数据库约束校验，防止非法字段和明显异常值进入业务数据。
\end{itemize}

数据库层增加非空约束、外键约束、枚举状态、唯一索引和必要的软删除字段。核心写操作记录审计日志，便于问题追踪和责任定位。

\subsection{合规性设计}

平台合规设计主要围绕个人信息保护、位置数据保护、垂钓规则提示和用户内容治理展开。

\textbf{个人信息保护：}平台仅收集实现功能所需的数据，例如昵称、头像、城市、出钓记录、帖子内容、用户偏好和用户主动填写的鱼获信息。对于精确位置、图片、私信和个性化画像等敏感数据，提供明确授权、可撤回和可删除机制。用户删除记录或帖子后，前端不再展示，后端进入软删除或清理流程。

\textbf{位置数据保护：}精确坐标不默认公开。社区内容对外展示时，根据用户选择和后端权限规则输出精确、水域模糊、仅城市或隐藏位置。平台不得将用户私密钓点用于公开推荐，除非用户明确授权并经过脱敏处理。

\textbf{禁钓与规则提示：}系统根据公开公告、人工维护规则、水域管理要求和平台风险标签提供合规提醒。规则数据保存来源、发布时间、有效期和适用范围。页面提示用户以当地最新公告和现场管理要求为准，避免把平台建议表述为执法或审批结论。

\textbf{用户内容治理：}社区帖子、评论、私信、活动群消息支持举报、隐藏、删除和审核状态。对于违法违规内容、广告引流、侵犯他人隐私、公开敏感钓点、破坏生态环境的内容，平台提供处理机制。

\subsection{安全验收要点}

安全验收不只检查功能是否可用，还应检查以下项目：

\begin{enumerate}
  \item 前端代码和构建产物中不存在高德 Web Service Key、DeepSeek Key、数据库密码等敏感信息。
  \item 发布帖子选择“模糊”或“隐藏”位置后，接口返回结果不包含可直接还原的精确坐标。
  \item 未登录或非本人用户不能修改、删除他人的记录和帖子。
  \item 第三方服务不可用时，系统返回可理解的错误或降级内容，不泄露堆栈。
  \item 日志中不记录明文密钥、完整精确位置和用户隐私原文。
  \item 备份文件、测试账号和初始化数据不包含真实个人敏感信息。
\end{enumerate}

通过上述措施，平台能够在地图、记录、社区、推荐和 AI 服务之间建立清晰的安全边界，满足课程项目技术投标文件对数据安全、隐私保护和合规设计的要求。
