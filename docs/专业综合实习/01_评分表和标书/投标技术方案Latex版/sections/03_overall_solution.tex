以「先记录，再连接，后服务」为核心链路：
\begin{enumerate}
  \item 先记录：开竿计时 → 真实鱼获录入 → 形成个人钓鱼档案
  \item 再连接：记录关联帖子 → 位置脱敏 → 社区互动
  \item 后服务：报告识别短板 → 推荐教程/活动/装备 → 产生服务收入
\end{enumerate}
