# recommendation_flow.png 图稿说明

该图用于正文“推荐算法与 AI 能力”章节，图名为 `figures/recommendation_flow.png`。

## 图示内容

推荐流程从左到右组织为 7 个节点：

1. 用户输入：城市、当前位置、目标鱼种、钓法偏好、检索半径。
2. 候选 POI：从 `data/pois.json` 读取钓点，正式阶段可替换为 PostGIS 空间检索。
3. 特征计算：计算鱼情、合规、距离、天气适配、设施便利、社交热度六类特征。
4. 风险校验：禁钓、限钓、极端天气、岸线安全等硬性风险优先拦截或降权。
5. 规则排序：输出 Top N 钓点、总分、分项分、推荐理由和 warning。
6. AI 解释：DeepSeek 或 mock 解释只读取规则排序结果，不重新排序、不新增点位。
7. 前端展示：在首页/详情页展示推荐列表、分项评分、风险提示和自然语言建议。

## 视觉建议

- 使用横向流程图，主路径用实线箭头。
- 风险校验节点可使用醒目的警示色，但不要让整图变成单一红色。
- 在“AI 解释”节点旁标注：`只解释，不决策`。
- 在“规则排序”节点旁标注六维权重：`0.25 / 0.25 / 0.15 / 0.15 / 0.10 / 0.10`。
