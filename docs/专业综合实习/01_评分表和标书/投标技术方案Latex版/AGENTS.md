# CLAUDE.md

本项目为课程实习《鱼你有图技术投标文件》的 LaTeX 写作目录。Claude Code 在本目录中工作时，必须遵守以下规则。

## 1. 项目目标

当前目录用于编写《鱼你有图技术投标文件》。

- **项目性质**：课程实习项目
- **文档类型**：技术投标方案文件
- **写作重点**：技术方案完整、结构规范、内容可验证、表达工程化
- **不写**：复杂商业分析、上市分析、财务测算或正式采购流程内容

## 2. 当前目录结构

项目采用单文件 LaTeX 模板：

```text
.
├── main.tex
├── figures/
└── CLAUDE.md
```

**要求：**

- 所有正文内容直接写入 `main.tex`
- 不再拆分 `sections/` 章节文件
- 配图统一放入 `figures/`
- 图片引用路径统一使用 `figures/xxx.png`
- 不要随意新增复杂目录

## 3. 编译要求

使用 XeLaTeX 编译（本地没有编译链，则只静态检查）：

```bash
xelatex main.tex
xelatex main.tex
```

**LaTeX 约束：**

- 使用 `ctexart` 或 `ctexrep`
- 不使用 `minted`
- 代码块使用 `listings`
- 表格使用 `tabularx`、`longtable` 或普通 `tabular`
- 图片使用 `graphicx`
- 不指定系统特有中文字体，避免跨设备编译失败
- 修改后应保证 `main.tex` 可直接编译

## 4. 写作原则

写作必须符合课程实习项目的真实情况。

**优先使用的表达方式：**

- 「当前 MVP 阶段已实现……」
- 「当前阶段采用 mock 数据支撑演示……」
- 「后续可扩展为……」
- 「该模块用于支撑……」
- 「该设计保证……可验证、可演示、可扩展……」

**禁止使用的表达方式：**

- 「行业领先」「颠覆式创新」「完全成熟商用」
- 「大规模高并发生产级系统」
- 「已与政府部门建立合作」
- 「已完成正式禁渔区权威数据接入」

除非用户明确提供证据，否则不得编造实现状态、性能指标、用户数量、合作单位、算法精度或商业收益。

## 5. 内容边界

当前技术方案重点围绕以下内容展开：

1. 项目概述
2. 需求分析
3. 总体技术方案
4. 系统架构设计
5. 业务流程与数据流程
6. 功能响应表
7. 核心功能设计
8. 数据模型与接口设计
9. 推荐模型与 AI 解释方案
10. 关键技术栈
11. 第三方服务接入设计
12. 安全、隐私与合规设计
13. 部署与运行方案
14. 测试与验收方案
15. 核心优势与创新点
16. 项目实施计划
17. 风险分析与应对措施
18. 后续扩展规划
19. 附录

**不应把非 MVP 内容写成已完成内容**，包括但不限于：

- 会员系统
- 赛事系统
- 商户系统
- 正式禁渔区数据合作
- 遥感自动识别钓点
- 完整用户权限体系
- 大规模生产数据库
- 支付系统

## 6. 修改规则

每次修改前先判断：

- 是否需要改 `main.tex`
- 是否需要新增图片占位
- 是否会破坏 LaTeX 编译
- 是否与当前项目实现一致

修改时：

- 保持原有章节编号结构
- 不大段删除已有内容，除非用户明确要求
- 不随意更换文档类和核心宏包
- 不引入复杂模板
- 不改变图片目录
- 不把全部内容堆成无标题长文
- 表格较宽时优先使用 `tabularx` 或 `longtable`
- 功能响应表必须包含「需求项、响应情况、实现说明、验证方式」

## 7. 章节写作规范

每个一级章节建议遵循：

1. 先说明本章目的
2. 再说明具体设计
3. 最后说明与项目 MVP 的关系

每个功能模块建议写清楚：

- 模块目标
- 输入数据
- 处理逻辑
- 输出结果
- 当前实现状态
- 验证方式

## 8. 表格规范

功能响应表建议使用以下状态：

| 状态 | 含义 |
|------|------|
| 已实现 | 功能已完成 |
| 部分实现 | 功能部分完成 |
| 待补充 | 计划中但尚未开发 |
| 后续规划 | 未来版本规划 |

不得使用模糊状态，如「基本可以」「应该能」「差不多完成」。

## 9. 图片规范

图片统一放入 `figures/`。

**建议图片命名：**

- `figures/system_architecture.png`
- `figures/business_flow.png`
- `figures/data_flow.png`
- `figures/map_page.png`
- `figures/poi_detail_page.png`
- `figures/recommendation_flow.png`

插图必须有图题，例如：

```latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.9\textwidth]{figures/system_architecture.png}
  \caption{系统总体架构图}
  \label{fig:system-architecture}
\end{figure}
```
